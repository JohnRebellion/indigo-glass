# Indigo Glass - Tokens

Single source of truth for palette, spacing, radius, blur, opacity, shadow, typography, motion.

## Files

| File | Purpose |
|------|---------|
| `indigo-glass.tokens.toml` | Canonical token values (edit this) |
| `codegen.py` | Reads tokens, emits per-layer artifacts (run this) |
| `out/css-vars.css` | CSS custom properties for web/Stylus (generated) |
| `out/scss-vars.scss` | Sass variables (generated) |
| `out/json-tokens.json` | JSON dump for JS consumers (generated) |
| `out/kde-palette.colors` | KDE color scheme partial (generated) |
| `out/wt-scheme.json` | Windows Terminal scheme (generated) |
| `out/density.css` | Compact-density CSS rules (generated) |

## Workflow

```bash
# Edit values
$EDITOR tokens/indigo-glass.tokens.toml

# Regenerate
python3 tokens/codegen.py

# Verify outputs in tokens/out/

# Commit both source + generated files
git add tokens/
git commit -m "tokens: bump indigo to ..."

# CI check: fail if generated files are stale
python3 tokens/codegen.py --check
```

## Why TOML > JSON for source

- Comments (explain why each value)
- Trailing commas don't matter
- Hand-editable without quoting hell
- Python 3.11+ has `tomllib` built-in

## What each layer consumes

| Layer | Reads | Notes |
|-------|-------|-------|
| Web (web/app.css.example) | `css-vars.css` (via `@import`) | Direct CSS custom properties |
| Stylus universal | `css-vars.css` + `density.css` (inlined) | Manual paste at version bump |
| VSCode color theme JSON | `json-tokens.json` (generated by future writer) | Token names map to VSCode keys |
| KDE color scheme | `kde-palette.colors` | Merged into `IndigoGlass.colors` |
| Konsole `.colorscheme` | reuses KDE palette | Manual sync |
| Windows Terminal | `wt-scheme.json` | Auto-injected by `windows/install.ps1` |
| GRUB theme | tokens via separate Jinja template (TODO) | Built into GRUB pixmaps |
| JetBrains `.icls` | future writer | XML emission TODO |
| Obsidian theme | future writer | CSS emission TODO |

## Why compact-density tokens

See [docs/DENSITY.md](../docs/DENSITY.md) for the rationale. Default OS chrome (Klassy/Material/Win Fluent) ships generous padding for new users + touch. Indigo Glass tightens for power-users on 1440p+ desktops without crowding letters.

## Why visionOS-translucent (NOT Apple Liquid Glass refraction)

We use `backdrop-filter: blur()` with low-opacity indigo tint. No refraction filter. No specular highlights. Backdrop blur = ambient context, never distracting.

See `[glass]` section in `indigo-glass.tokens.toml`.

## P3 wide-gamut overlay

```css
@media (color-gamut: p3) {
  :root {
    --ig-indigo: color(display-p3 0.36 0.40 0.81);
    /* ... */
  }
}
```

On P3-capable monitors (MacBook XDR, modern OLED), saturation reads ~30% more vivid without changing the perceptual hue. Falls back to sRGB hex on non-P3.

## Accessibility

`prefers-reduced-transparency` -> blur disabled, opacity raised to 1.0.
`prefers-reduced-motion` -> durations zeroed.

Built into `out/css-vars.css` as `@media` queries.
