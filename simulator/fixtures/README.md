# Stock fixtures

The left ("stock") lane of every `/desktop/<id>/` page renders from these
files. They are copies of what the desktop ships before Sage Ink is
installed, taken from the Fedora 44 / Plasma 6 host on 2026-09-25 unless the
file's own header says otherwise. Each one keeps its upstream licence
(Breeze, Konsole, Klassy: LGPL-2.1+/GPL-2.0+; Adwaita: LGPL-2.1+).

They are frozen on purpose: the comparison must not change because a
package updated. Refresh a fixture deliberately, and say so in the commit.
